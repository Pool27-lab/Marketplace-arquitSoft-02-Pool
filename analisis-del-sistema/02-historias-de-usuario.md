# Historias de usuario

## Descripción

Las historias de usuario permiten describir las funcionalidades del marketplace desde la perspectiva de los actores que interactúan con el sistema.

## Historias de usuario

### HU01 - Buscar productos

**Como** cliente,
**quiero** buscar y consultar productos,
**para** encontrar el producto que necesito.

### HU02 - Gestionar productos

**Como** seller,
**quiero** registrar y gestionar mis productos,
**para** ofrecerlos a los clientes.

### HU03 - Gestionar carrito

**Como** cliente,
**quiero** gestionar los productos de mi carrito,
**para** preparar los productos que deseo comprar.

### HU04 - Realizar pedido

**Como** cliente,
**quiero** realizar un pedido con los productos de mi carrito,
**para** completar mi compra.

### HU05 - Gestionar sellers

**Como** administrador,
**quiero** gestionar los sellers de la plataforma,
**para** administrar a los vendedores registrados.

### HU06 - Consultar pedidos

**Como** cliente,
**quiero** consultar mis pedidos y su estado,
**para** conocer el estado de mis compras.

## Resumen de historias

| ID   | Actor         | Funcionalidad                   |
| ---- | ------------- | ------------------------------- |
| HU01 | Cliente       | Buscar y consultar productos    |
| HU02 | Seller        | Registrar y gestionar productos |
| HU03 | Cliente       | Gestionar productos del carrito |
| HU04 | Cliente       | Realizar pedidos                |
| HU05 | Administrador | Gestionar sellers               |
| HU06 | Cliente       | Consultar pedidos y su estado   |
