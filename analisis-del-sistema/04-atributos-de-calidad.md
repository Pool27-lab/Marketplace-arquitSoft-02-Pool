# Atributos de calidad

## Descripción

Los atributos de calidad representan las características que debe cumplir el marketplace para garantizar un funcionamiento adecuado, especialmente ante una cantidad elevada de usuarios y operaciones simultáneas.

## Atributos de calidad

### AC01 - Rendimiento

El sistema debe responder rápidamente a las consultas de productos y a las operaciones del carrito, incluso cuando exista una cantidad elevada de usuarios concurrentes.

### AC02 - Disponibilidad

El sistema debe mantenerse disponible durante periodos de alta demanda, como campañas comerciales y promociones.

### AC03 - Escalabilidad

El sistema debe permitir aumentar la capacidad de usuarios y solicitudes sin presentar una degradación significativa del rendimiento.

### AC04 - Seguridad

El sistema debe proteger la información de los usuarios, productos y compras frente a accesos no autorizados.

### AC05 - Mantenibilidad

El sistema debe contar con una estructura organizada que permita realizar modificaciones, correcciones y mejoras sin afectar innecesariamente otras funcionalidades.

## Resumen

| ID   | Atributo       | Descripción                                                      |
| ---- | -------------- | ---------------------------------------------------------------- |
| AC01 | Rendimiento    | Responder rápidamente ante operaciones y usuarios concurrentes.  |
| AC02 | Disponibilidad | Mantener el sistema disponible durante periodos de alta demanda. |
| AC03 | Escalabilidad  | Soportar el crecimiento de usuarios y solicitudes.               |
| AC04 | Seguridad      | Proteger los datos y controlar los accesos.                      |
| AC05 | Mantenibilidad | Facilitar cambios, correcciones y mejoras del sistema.           |
