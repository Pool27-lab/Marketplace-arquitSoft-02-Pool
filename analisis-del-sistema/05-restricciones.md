# Restricciones del sistema

## Descripción

Las restricciones establecen las condiciones y tecnologías que deben considerarse durante el desarrollo del marketplace.

## Restricciones

### RC01 - Aplicación web

El marketplace debe desarrollarse como una aplicación web accesible mediante un navegador.

### RC02 - Control de versiones

El proyecto debe utilizar Git y GitHub para el control de versiones y seguimiento de los cambios realizados durante el desarrollo.

### RC03 - API REST

La comunicación entre la aplicación web y los servicios del sistema debe realizarse mediante una API REST.

### RC04 - Pasarela de pago externa

El sistema debe integrarse con una pasarela de pago externa para procesar las transacciones realizadas por los clientes.

### RC05 - Servicio de envío externo

El sistema debe integrarse con un servicio externo para gestionar la información relacionada con el envío y entrega de los pedidos.

## Resumen

| ID   | Restricción          | Descripción                                             |
| ---- | -------------------- | ------------------------------------------------------- |
| RC01 | Aplicación web       | El sistema será accesible mediante navegador web.       |
| RC02 | Control de versiones | Se utilizará Git y GitHub.                              |
| RC03 | API REST             | La comunicación se realizará mediante una API REST.     |
| RC04 | Pasarela de pago     | Se utilizará un servicio externo para procesar pagos.   |
| RC05 | Servicio de envío    | Se utilizará un servicio externo para gestionar envíos. |
