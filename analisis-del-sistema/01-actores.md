# Actores del sistema

## Descripción

Los actores son las personas, organizaciones o sistemas externos que interactúan con el marketplace de productos para mascotas.

## Actores principales

| ID  | Actor         | Tipo    | ¿Qué necesita realizar?                                                                                                           |
| --- | ------------- | ------- | --------------------------------------------------------------------------------------------------------------------------------- |
| A01 | Cliente       | Usuario | Buscar productos, consultar información, agregar productos al carrito, realizar pedidos, efectuar pagos y consultar sus pedidos.  |
| A02 | Seller        | Usuario | Registrar, actualizar y gestionar sus productos, consultar sus productos y administrar la información relacionada con sus ventas. |
| A03 | Administrador | Usuario | Administrar la plataforma, gestionar usuarios y sellers y supervisar el funcionamiento general del marketplace.                   |

## Sistemas externos

| ID  | Actor                   | Tipo            | ¿Qué función realiza?                                                         |
| --- | ----------------------- | --------------- | ----------------------------------------------------------------------------- |
| A04 | Pasarela de pago        | Sistema externo | Procesar los pagos realizados por los clientes durante la compra.             |
| A05 | Servicio de envío       | Sistema externo | Gestionar la información relacionada con el envío y entrega de los pedidos.   |
| A06 | Servicio de facturación | Sistema externo | Generar los comprobantes de pago correspondientes a las compras realizadas.   |
| A07 | ERP                     | Sistema externo | Proporcionar información relacionada con los productos y el stock disponible. |

## Resumen

El marketplace interactúa con tres actores principales: Cliente, Seller y Administrador. Además, se integra con sistemas externos para realizar funciones relacionadas con el pago, envío, facturación y consulta de productos y stock.
