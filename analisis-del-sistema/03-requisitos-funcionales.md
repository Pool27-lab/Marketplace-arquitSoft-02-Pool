# Requisitos funcionales

## Descripción

Los requisitos funcionales describen las funcionalidades que el marketplace debe proporcionar para atender las necesidades de sus usuarios y sistemas externos.

## Requisitos funcionales

### RF01 - Buscar productos

El sistema debe permitir al cliente buscar productos mediante diferentes criterios de búsqueda.

### RF02 - Consultar información de productos

El sistema debe permitir al cliente consultar la información, características y disponibilidad de los productos.

### RF03 - Gestionar productos

El sistema debe permitir al seller registrar y actualizar sus productos publicados en el marketplace.

### RF04 - Gestionar carrito

El sistema debe permitir al cliente agregar, modificar y eliminar productos de su carrito de compras.

### RF05 - Generar pedido

El sistema debe permitir al cliente generar un pedido a partir de los productos seleccionados en su carrito.

### RF06 - Consultar pedidos

El sistema debe permitir al cliente consultar sus pedidos y conocer el estado de cada uno.

### RF07 - Gestionar sellers

El sistema debe permitir al administrador registrar, actualizar y desactivar sellers de la plataforma.

### RF08 - Consultar detalle de pedido

El sistema debe permitir al cliente consultar el detalle de un pedido realizado.
